# Changelog

All notable changes to the PDFsam Basic Community Manual will be recorded here.

## [1.0] — 2026-09-17

### First public release

- Established the PDFsam Basic Community Manual project.
- Organized the guide as a versioned community manual.
- Included practical coverage of Merge, Split, Mix/Interleave, Rotate, and Extract workflows.
- Included output file-name placeholders and examples.
- Included selected silent-install, runtime, workspace, Java, and troubleshooting information.
- Added a feedback path for corrections and suggestions from readers.
