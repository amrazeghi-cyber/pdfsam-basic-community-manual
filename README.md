# PDFsam Basic Community Manual

An independent, community-created practical guide for **PDFsam Basic**.

The goal of this project is simple: build a useful manual from real use, testing, troubleshooting, and community feedback. The manual will improve incrementally rather than waiting for a theoretically perfect edition.

## Current release

**Version 1.0 — September 2026**

The first public edition covers common PDFsam Basic workflows including merging, splitting, mixing/interleaving, rotating, extracting pages, output file-name placeholders, workspaces, selected installation/runtime options, and troubleshooting notes.

Version 1.0 is the starting point, not the final word. Future releases will incorporate corrections, clearer examples, software changes, additional testing, and useful feedback from readers.

## Downloads

Release files will be added to this repository. The editable DOCX source is retained so the guide can continue to evolve.

## Feedback and contributions

Found an error? Have a clearer workflow, a useful troubleshooting case, or an idea for the next version? Please open a GitHub Issue in this repository. Useful community feedback may be incorporated into future releases, with credit where appropriate and desired.

## Sources and verification

The guide is assembled from practical use, testing, and publicly available technical information. Version-specific behavior can change, so important procedures should be checked against the software version being used. Future editions will expand and refine source notes where useful.

## Support

The manual is intended to remain freely accessible. Optional support/donation information may be added later to help sustain testing, documentation, and future community manuals.

## Project philosophy

**Publish → test → listen → correct → expand.**

A useful first edition is more valuable than an unfinished perfect edition.
